## E-Belediye Sitesi

Bu repo, HTML, CSS ve JavaScript kullanılarak geliştirilmiş statik web sayfalarını içerir.  
Proje, web geliştirme becerilerini sergilemek ve portföy oluşturmak amacıyla geliştirilmiştir.  

E-Belediye sitesi, vatandaşların belediye hizmetlerine dijital olarak hızlı ve kolay erişim sağlamasını amaçlar.  
Çevresel hizmetler, acil hizmetler, kayıp eşya bildirimi, online randevu alma, topluluk hizmetleri ve belediye projeleri gibi çeşitli hizmetler dijital platformda sunulmaktadır.  
Bu sayede vatandaşlar, belediye ile daha etkin iletişim kurabilir ve hizmetlere daha kolay erişebilir.
